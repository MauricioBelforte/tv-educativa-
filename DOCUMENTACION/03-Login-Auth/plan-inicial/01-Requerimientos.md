# Requerimientos - Modulo de Login y Autenticacion

## Problema
Los usuarios que abren la URL del proyecto pueden ver todas las listas privadas y canales sincronizados.

## Objetivos
1. Proteger el acceso a listas privadas con contrasena
2. Usuarios no autenticados ven solo canales por defecto
3. Sesion persistente entre recargas
4. APIs protegidas

## Alcance
- Login modal, verificacion server-side, estado persistente, APIs protegidas
